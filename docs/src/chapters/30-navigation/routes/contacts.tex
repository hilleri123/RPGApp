\route{Контакты}{/contacts}{url:contacts}

\paragraph{Назначение}
Связаться с командой и скачать это руководство. Страница открыта всем, вход не требуется.

\screenshotOptional{user/contacts.png}{страница «Контакты»}

\component{Скачивание руководства}{cmp:contacts:download}

\paragraph{Назначение}
Отдаёт актуальную версию руководства пользователя в PDF --- того самого документа, который вы читаете.

\action{Скачать руководство}{act:contacts:download}
\uilink{Кнопка ``Скачать PDF''}{/rpg-master-user-guide.pdf}{ui:contacts:btn-download}
\paragraph{Действие}
Скачивает файл \texttt{rpg-master-user-guide.pdf}. Файл лежит статикой, отдельного входа для скачивания не нужно --- ссылку можно переслать кому угодно.

\component{Способы связи}{cmp:contacts:channels}

\paragraph{Назначение}
Перечисляет каналы обратной связи: почту, Telegram-бота, чат сообщества и адрес для сообщений об ошибках. Конкретные адреса задаёт владелец площадки.
