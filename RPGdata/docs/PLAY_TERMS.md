# Термины игрового цикла

| Термин (код) | По-русски | Описание |
|--------------|----------|----------|
| **Prep scenario** (`is_session_snapshot=false`) | Сценарий (подготовка) | Wiki мастера: локации, NPC, экспозиции. Не меняется во время игры. |
| **Launched scenario** (snapshot + `lifecycle_status=running`) | Запущенный сценарий | Копия prep при первом запуске. Живёт между подходами и партиями. |
| **Approach** (`GameSession`) | Сессия / подход | Один заход за стол: лобби → игра → закрытие. Не уничтожает запущенный сценарий. |
| **Party** (`ScenarioParty`) | Партия | Группа игроков в запущенном сценарии (до 5 параллельных линий). |
| **Episode tag** (`ep:*` в tags) | Тег эпизода | Область видимости сущности внутри одного сценария. |
| **Party tag** (`party:*` в tags) | Тег партии | Какие партии «затрагивают» сущность. |
| **Player seen** (`PlayerSeenState`) | Видимость игрока | Per-user: какие локации/NPC/предметы игрок уже видел (в БД). |
| **Campaign** | Кампания | Цепочка эпизодов с общим launched-миром и carryover между подходами. |

## Правила

1. Одновременно **только один активный подход** на запущенный сценарий.
2. Закрытие подхода **не удаляет** Redis-состояние мира (`launched:{id}`).
3. Закрытие запущенного сценария (`lifecycle_status=closed`) архивирует мир.
4. Игрок видит только сущности своей партии + без party-тега + своё seen-состояние.
